# 💳 Financial Cards Dashboard

Um dashboard de cartões e saldos financeiros desenvolvido para praticar a arquitetura de estilização com SASS e a metodologia BEM (Block Element Modifier).

## 🚀 Tecnologias
- **HTML5** (Estrutura semântica)
- **SASS** (Pré-processador para CSS modular)
- **Metodologia BEM** (Organização de classes)
- **Node.js** (Ambiente de desenvolvimento)

## 📋 Funcionalidades
- Visualização de Saldos Disponíveis.
- Card de Cartão de Crédito com detalhes de limite.
- Card de Informações do Cliente.
- Layout responsivo preparado para integração.

## 🔧 Como rodar o projeto
1. Instale as dependências: `npm install`
2. Inicie o compilador SASS: `npm run watch:sass`
3. Inicie o servidor local: `npm start`
